# My Daily Tasks - Android Studio Project

A modern, offline-first Android reminder and task management app built with:
- **Jetpack Compose & Material 3**
- **Room Database** (local offline SQLite persistence)
- **AlarmManager & NotificationChannel** (reliable exact reminders)
- **Navigation Compose**
- **Reports & Calendar Overview**

## How to build APK on Android phone (No computer required):
1. Push this project or upload to a free GitHub repository.
2. The included GitHub Actions workflow (`.github/workflows/build-apk.yml`) will automatically compile `app-debug.apk`.
3. Open GitHub on your phone -> Go to "Actions" -> Click the latest build -> Download "MyDailyTasks-debug-apk" artifact and install!
